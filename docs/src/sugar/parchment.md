[ParchmentMC Mappings](https://parchmentmc.org/) can be added by simply specifying the `parchment_mappings_version` (1) in the root projects `gradle.properties` file.
{ .annotate }

1.  for example `2024.11.17`

They will be automatically used by any project/sub-project using [NeoForge](/mod-loaders/neoforge), [Fabric](/mod-loaders/fabric), [Common](/mod-loaders/common) or [Forge](/mod-loaders/forge)
